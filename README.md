# RyoGeese-Dash

RyoGeese 的独立游戏信息显示插件，当前用于正式服 12.1.5 暗牧。

自有源码采用 **GPL-3.0-only**，作者：手电加鞭。见 [LICENSE](LICENSE)；插件文件夹内也保留一份许可全文。

插件只显示游戏信息，不计算技能推荐、不自动施法。软件与插件分别维护：[RyoGeese 软件](https://github.com/muttsf/RyoGeese)。

## 安装

1. 退出游戏。
2. 把本仓库内的 **MindBlastBox01** 整个文件夹放入当前正式服的 `Interface/AddOns/`。
3. 进入角色，确认插件启用。不要把 `RyoGeese-Dash` 仓库根目录直接当作插件文件夹。

插件版本为 `1.45-S1`，接口 `120105`，布局 `L16`。不另做插件安装器或定制压缩包。

## 使用

- `/dashconfig`：打开设置；`/dash`：查看状态。
- 解锁后拖动插件标题，调整位置；完成后锁定。
- 面板需要完整可见。位置、大小或字号变化后，在软件中重新定位。
- 位置、大小、字号等由游戏保存在每角色 `MindBlastBox01DB` 中，软件卸载不会删除。

ABCD 固定槽位分别显示技能冷却/充能、目标 DOT、血量/狂乱资源和玩家 BUFF。插件通过游戏引擎提供的显示通道呈现信息；未知值与正常空槽分别处理。

当前跨职业完整模板切换尚未完成，恶魔术只是后续扩展计划。游戏内图标是对游戏纹理的引用，仓库不附带提取的图标图片。

现有槽位说明见 [README.txt](README.txt)。本次只补作者、许可与摘要，Lua运行逻辑、1.45-S1版本和L16布局不变。
