RyoGeese-Dash
当前为首次发布准备的插件源码；独立于RyoGeese软件维护，不另制作插件安装包或压缩包。
当前插件文件夹名仍为MindBlastBox01，不能直接改成GitHub仓库名。
版本1.45-S1，布局L16，接口120105，当前用于正式服12.1.5暗牧。
本次仅补许可/版权注释及TOC作者/许可/摘要；运行逻辑和版本不变。

安装
退出游戏，把本仓库内MindBlastBox01整个文件夹放到当前正式服Interface/AddOns下。
进入角色后确认插件启用。不是把RyoGeese-Dash整个仓库目录当成插件文件夹。
插件只显示游戏事实，不推荐技能、不自动施法、不代替RyoGeese软件。

布局
A列：技能冷却、充能或当前使用次数。A1心灵震爆，A2触须猛击，
A3虚空洪流，A4暗言术：灭，A5能量灌注，A6虚空形态，A7虚空齐射。
B列：目标DoT，B1暗言术：痛，B2吸血鬼之触，B3暗言术：癫。
C列：C1目标血量百分比，C2玩家狂乱当前值及上限；第二资源C3是扩展预留。
D列：玩家BUFF，D1熵能裂隙，D2虚空形态，D3能量灌注。
固定行列保持位置，不按当前有没有效果随意挪格。未知值与正常空槽不是同一种情况。
核心显示借用游戏引擎提供的通道；不能把受保护数值改成Lua自行计算的冷却或光环倒计时。

设置与记录
/dashconfig打开游戏内设置；/dash查看状态。
解锁后拖动标题调整位置，保持面板完整可见；完成后锁定。
位置、大小、字号等由每角色MindBlastBox01DB保存，游戏负责写入SavedVariables。
软件卸载不删除这些游戏设置。调整布局、字号或位置后，要在软件中重新定位。
跨职业完整模板切换尚未完成；恶魔术以后在同一槽位框架下扩展，不能写成已经支持。
